<h1>MidiKeypad</h1>
A small Midi Keypad made for Hack Club's Half-Life!

<h2>Overview</h2>
This project is a small, instrument made with capacitative pads. You are meant to touch the pads, and use the keys to play specific notes. 

The project itself is based off of <a href="https://github.com/KaiPereira/MIDI-Keypad">KaiPereira's MIDI Keypad</a>!

There are currently no large deviations from his project present, however, some indicator lights for specific notes are currently in the works.
